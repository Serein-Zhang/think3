# 可复用经验卡

一张卡记录一个机制。简单复盘无需建卡；这不是自动写入长期记忆的指令。

- **经验名称与日期：**
- **事项标识（需要跨轮跟进时）：** 沿用已有标识，避免重复派发。
- **状态：** 候选 / 试用 / 已采用 / 已否定 / 已撤回。
- **问题或有效做法：**
- **支持证据：** 对象、条件、版本、结果和来源。
- **反例与替代解释：** 没有发现反例不等于不存在。
- **机制判断：** 已确认 / 有支持的推断 / 未确认假设。
- **适用范围：** 什么情况下可用，什么情况下不能迁移。
- **具体改变：** 保留、实施或停止哪一步。
- **沉淀落点：** 本次记录 / 项目说明 / 代码与测试 / 工具 / skill / 需明确请求的长期记忆。
- **负责人、授权与实施状态：**
- **复核意见（如需要）：** 当前范围内支持 / 需修订 / 证据不足；具体依据与最小补证动作。
- **下一次验证机会：** 用什么观察判断效果；这不自动创建调度。
- **撤回条件：** 什么结果说明无效、代价过大或前提改变。
- **后续结果：** 实际变化、残余问题；引用原卡而不覆盖原始失败证据。
