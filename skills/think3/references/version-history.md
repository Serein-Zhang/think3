# 版本跟踪

`SKILL.md` 的 `metadata.version` 是运行版本的唯一来源，CLI 不另存硬编码版本号。

```sh
python3 /path/to/think3/scripts/tracker.py --version
```

命令返回 `name`、`version` 和 `schema_version`，不需要数据库路径，也不创建或读取账本。

- `version`：当前运行包的版本。排查问题或交接时记录它；正常使用不必每次宣布。
- `--version.schema_version`：本版新建账本采用的结构版本，与 Skill 发布版本分开；当前为2。导出中的 `schema_version` 是被导出账本的实际版本，可以为1或2。
- 导出中的 `generator.version`：生成该份导出的版本，不代表历史事项最初由该版本创建。
- 升级前保留旧运行目录和对应账本的合适备份，核对变更后再替换。查询版本或阅读更新记录不会自动联网、下载或安装。
- 维护者每次发布更新入口版本、下方变更记录并重新构建；涉及数据库结构变化时另行定义迁移步骤，不仅改发布版本号。
